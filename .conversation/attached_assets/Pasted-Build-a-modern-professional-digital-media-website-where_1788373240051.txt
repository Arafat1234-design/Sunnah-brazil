Build a modern, professional digital media website where users can discover and download legally available books and videos.

The website should feel like a premium digital library, with a clean, fast, mobile-first design because many users will access it from their phones.

CORE FEATURES:

HOMEPAGE
Large hero section with the website name and a short description.
Search bar for finding books and videos.
Featured books section.
Featured videos section.
Recently added content section.
Clear buttons such as "Browse Books" and "Watch Videos".
Modern animations and smooth transitions.
Fully responsive on phones, tablets, and desktop.
BOOK LIBRARY Create a dedicated Books page.
Display books in attractive cards.
Each card should show:
Cover image
Book title
Author
Category
Short description
File format (PDF/EPUB/etc.)
Download button
Add categories such as:
Fiction
Education
Business
Technology
Personal Development
Children's Books
Other
Add search and filtering.
Create an individual book details page.
Users should be able to download books directly to their phone.
Only allow books that are public domain, openly licensed, or uploaded with permission.
VIDEO LIBRARY Create a dedicated Videos page.
Display video thumbnails in cards.
Show title, description, upload date, category, and duration.
Allow users to watch videos directly on the website.
Add a download button where downloads are enabled.
Add video search and categories.
Create an individual video page with a video player.
ADMIN DASHBOARD Create a secure admin dashboard. The administrator should be able to:
Upload books.
Upload book cover images.
Add/edit/delete book information.
Upload videos.
Add video thumbnails.
Add/edit/delete video information.
Choose whether a video can be downloaded.
Manage categories.
See uploaded content.
Remove content.
See basic download/view statistics.
FILE STORAGE Do NOT store large video files directly inside the website code or Git repository.
Create the application so that media files can be stored using an external object-storage service such as Cloudflare R2 or another compatible storage provider.

The database should store metadata such as:

title
author
description
category
thumbnail URL
file URL
upload date
file type
file size
download permissions
DATABASE Use a proper database for books, videos, users/admin accounts, categories, and download statistics.

SECURITY

Create secure admin authentication.
Normal visitors must NOT have access to the admin dashboard.
Validate uploaded files.
Restrict dangerous file types.
Add file-size limits.
Protect admin routes.
Never expose private storage credentials in frontend code.
Use environment variables for API keys and secrets.
MOBILE EXPERIENCE The website must be designed mobile-first. Downloads should work properly on Android and iPhone. Buttons should be large and easy to tap. Video playback should work well on mobile. The website should load quickly even on slower connections.

DESIGN Use a modern premium design.

Clean typography
Large book covers
Attractive video thumbnails
Rounded cards
Subtle animations
Good spacing
Dark/light theme toggle
Professional navigation bar
Responsive footer
NAVIGATION Create:
Home
Books
Videos
Categories
About
Contact
Admin Login
SEARCH Create a global search system that searches both books and videos. Show results grouped into: Books Videos

PERFORMANCE

Optimize images.
Lazy-load video thumbnails.
Lazy-load content where appropriate.
Avoid unnecessary animations that slow down mobile devices.
Keep the website fast.
SEO Add:
Proper page titles
Meta descriptions
Open Graph metadata
SEO-friendly URLs
Sitemap
Robots.txt
LEGAL Include a Terms of Service page and Copyright/Content Policy page. The platform must be designed for content that the administrator has the legal right to distribute. Include a mechanism for reporting copyrighted material and removing unauthorized content.
TECHNICAL REQUIREMENTS:

Build the frontend and backend.
Use a clean, maintainable project structure.
Make the website production-ready.
Use environment variables for secrets.
Do not hardcode API keys.
Include clear setup instructions.
Include database setup instructions.
Include storage setup instructions.
Include deployment instructions for a low-cost/free hosting setup.
Make sure the application can eventually handle large numbers of users and files.
Before finishing, test:

Mobile responsiveness
Book search
Video search
Book downloads
Video playback
Video downloads
Admin login
Admin uploads
Database operations
Error handling
Unauthorized admin access
Do not just create a visual mockup. Build the actual functional application with working frontend, backend, database integration, authentication, uploads, and downloads.
